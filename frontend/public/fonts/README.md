# Font giao diện Cinematic Noir

Font self-hosted lấy từ Google Fonts ngày 14/10/2026, định dạng WOFF2 cho Latin, Latin mở rộng và tiếng Việt.

- Be Vietnam Pro: weights 100/300/400/500/700/900; https://github.com/google/fonts/tree/main/ofl/bevietnampro
- Noto Serif: Thin Italic 100; https://github.com/google/fonts/tree/main/ofl/notoserif

Giữ license SIL Open Font License trong các file OFL kèm theo. Không sửa glyph/font. Định nghĩa font-face và unicode-range nằm tại `src/app/fonts.css`; chạy local không cần gọi Google Fonts. Đây là cặp font thay thế ZTNature theo yêu cầu thiết kế, không tuyên bố dùng ZTNature.
